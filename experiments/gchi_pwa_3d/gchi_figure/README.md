# G-ChI bifurcation figures

Two separate figures compare calcium and IP3 equilibria and cycle extrema; h is not shown. Columns AM (the AM-parameter G-ChI set labeled AFM in gchi_modes) and FM; rows original G-ChI and chosen PWA. Equilibrium locations for G-ChI are sampled roots, not exhaustive continuation. Stable cycles are saved forward detections; red open circles are candidate unstable periodic orbits with numerical closure and Floquet checks. Purple diamonds are reference fold candidates, not a proof of fold nondegeneracy.

PWA candidates: AFM `runs/afm-calcium-c1-01/candidate-2.json`, FM `runs/fm-topology-free-c1-01/candidate-3.json`. Cycle validation results are `validation-2.json` and `validation-3.json` in the same respective directories. AM reference unstable branch is from `gchi_am/output/continuation.json` (filter rho>1.001, amplitude>1e-4, residual<1e-7). AM PWA unstable branch is `am_pwa_unstable.json`: finite-difference shooting followed by independent variational DOP853 check, neutral multiplier error <1e-4 and closure <1e-6; finite integration across nonsmooth thresholds, tolerance convergence and completeness not established. FM reference unstable branch `fm_reference_unstable.json` uses shooting plus variational multipliers, closure <1e-7. No unstable FM PWA branch or fold is claimed for the selected candidate. Previously saved FM first-return fold belongs to a different candidate and is excluded.

Run `OPENBLAS_NUM_THREADS=1 python experiments/gchi_pwa_3d/gchi_figure/plot_article.py`. Intermediate scripts `find_unstable.py`, `find_pwa_unstable.py` and `check_pwa.py` perform the additional numerical searches; `check_pwa.py` filters and overwrites `am_pwa_unstable.json`. Search trajectories and finite-time criteria do not establish completeness or rule out other branches. Figures use linear glutamate axes to match the article; near-zero FM details are compressed.
