# AM G-ChI fold fit: preliminary

This experiment starts from `runs/afm-calcium-c1-01/candidate-2.json`, retains all three calcium knots and uses the equilibrium-anchor null space. It targets the reference G-ChI AM fold candidate at gamma=3.7500176522854862 uM. The saved result is not yet a verified fold: the first-return closure is about 3.20e-5, det(DP-I) about -1.27e-5, and nondegeneracy and nearby branches have not been checked. Exact affine first-return and independent adaptive integration agreed at tested tolerances. Both lower and the upper region had negative largest real eigenvalue, the middle region positive; the upper is close to zero (about -0.001). Sampled physicality does not prove invariance.

Validation at 12 points found 12/12 cycles, using DOP853 for 1000 s from reference-cycle initial states. Conditional MAE (Cmin, Cmax, Imin, Imax, period) is (0.04474 uM, 0.07995 uM, 0.05639 uM, 0.04914 uM, 0.92844 s), worse than source candidate (0.01520, 0.01293, 0.01032, 0.01047 uM; 0.36099 s). These nominally held-out inputs were not a new validation set selected after optimization; the starting candidate was fitted previously. No claim that fold fitting improves the model.

`probe.py` first performs soft full-orbit shooting; `exact_all.py` then optimizes first-return residuals with an exact affine flow and `exact_stable.py` adds soft regional-stability penalties. Run from any working directory in that order with `OPENBLAS_NUM_THREADS=1`. The approximate shooting finite-difference optimization can be sensitive to tolerances and computer, and its stationarity is not established. Saved `candidate_stable.json` and `validation_stable.json` are pilot outputs, not promoted models. Reference fold itself is a numerical candidate; local nondegeneracy/transversality remain to be checked. `gchi_figure/am_pwa_unstable.json` contains the starting AM unstable orbit data.
