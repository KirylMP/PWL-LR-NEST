# First-return fold in the 3D FM PWA model

This is an exploratory implementation motivated by the attached 2D Li–Rinzel manuscript, not an assertion that the planar trace formula applies in 3D. Glutamate is a fixed parameter and the state is (C,h,IP3). The previous continuous PWA model has 30 scalar field coefficients and three fixed 3D equilibria. Their 3-by-10 basis matrix has rank 3: the saved null-space basis gives 21 field coordinates that preserve all three equilibria exactly. With two unknown coordinates (h,IP3) on a section and three equations — two first-return fixed-point equations and det(DP-I)=0 — the local solution dimension is 21+2-3=20 when the selected 3-by-3 coefficient Jacobian is nonsingular. `analysis/fm-first-return/chart.json` preserves the exact null-space basis, pivot indices and derivative diagnostics. The scaled pivot condition number at the located fold is about 123; this is a local chart, not a global parametrization.

The section C=.2 uM is away from all switching planes. `poincare_fm_exact.py` propagates in each affine cell with a 4-by-4 augmented matrix exponential and finds the next section/threshold crossing with scalar bracketing. It uses the first positive, transverse section crossing. The derivative includes the return-time projection and the product of regional state-transition matrices. Because the vector field is continuous at transverse switches, the saltation matrix is identity. Event brackets use a finite scan step: multiple crossings within one step and grazing can be missed. Always repeat with smaller scan steps and independently integrate. `poincare_fm.py` gives an independent adaptive ODE and variational implementation.

At the seed-3 field, the return time is about 12.691 s and det(DP-I)~.982765, so it is not near a fold at the target. A 3-variable local solve finds an algebraic fold but loses lower-region stability. A local implicit continuation then finds `analysis/fm-first-return/fold.json` at the **fixed** reference gamma 21.2025538651 uM, with all three equilibria pinned and stable/stable/unstable/stable regional eigenvalue signs. The first-return closure and fold determinant residual are approximately 3e-12 with matrix exponentials. At half the scan step and with adaptive integration, residuals stay small (see `fold.json`). The minimum absolute threshold crossing speed is about .00729; all observed switches are transverse, although this crossing is relatively slow and deserves care.

`fold-verification.json` contains finite-difference return-map estimates of the nondegeneracy and parameter-transversality coefficients at three steps: about -2.6212 and -0.02138 with the stated eigenvector normalization. At gamma target minus .001, .01 and .05, numerical root solving finds one stable and one unstable cycle: at minus .001 the return-map radii are ~.98967 and 1.01086. These provide numerical evidence of a generic cycle fold, not a formal proof or exhaustive global continuation. `orbit-verification.json` confirms an adaptive section trajectory crosses upward at t=0 and t~11.17211 s with no earlier detected upward section return; full-flow closure is ~3.4e-13. Dense samples give Cmin~.01687, Cmax~.94155, IP3 range~2.62676..3.61938 uM. The fixed reference fold has Cmin~.03523, Cmax~1.15126, IP3 range~.85891..3.23238 uM and period~12.416 s. Therefore this field gets the fold parameter and local stability topology but not the fold shape/IP3.

The field is not a complete FM fit. `validation.json` found only 5/12 standard trajectories passing the finite physical/cycle checks; seven trajectories entered negative IP3 from the tested initial states. `onset.json` has periods ~28.65 s at gamma .0203, versus ~154.19 s in reference G-ChI. Those are finite integrations, not proofs that other cycles cannot exist. The lower-onset points are also used in fitting and are not held out. `local-branches.json` and `local-branches.png` show just three sampled parameter values on the local stable/unstable branches near the candidate fold, not a full bifurcation diagram.

`refine_first_return.py` locally optimizes 20 outer variables (18 remaining null-space coordinates plus two section coordinates). At each evaluation it solves the three selected coefficient values from the first-return equations; candidates are retained only when the root residual and stability/sample-physical checks pass. It matches reference field-return proxies at four gamma values, including first-return times near onset, and fold extrema. A solve failure receives a penalty. This local projection may fail or jump if the chart becomes ill-conditioned; it fixes the currently observed switch itinerary, and finite scans/soft reference residuals do not prove global positivity or a fundamental cycle for every point. `check_first_return_candidate.py` independently compares first-return closure and derivative using adaptive integration and finer matrix-exponential bracketing. `verify_poincare_fold.py` numerically tests nondegeneracy and probes stable/unstable branches; it does not replace proof.

A local 14-evaluation exploratory refinement changed the surrogate loss only from 43.31 to 43.09 (an improvement of about 0.5%); its stop criterion fired with very large first-order optimality. It did not establish an improvement of the full FM model. New runs start from the documented fold, not from an undocumented finite-difference point.

## Optional server refinement

From the repository root after `git pull --ff-only`:

```bash
cd experiments/gchi_pwa_3d/gchi_modes
source ../gchi_pwa_trial/.venv/bin/activate
bash run_first_return_refinement.sh runs/fm-first-return-01 4 4 20 \
  | tee fm-first-return-summary.txt
```

Arguments are a new or empty run directory, seed count, workers, and outer least-squares evaluation limit. The Jacobian uses 40 additional central-difference evaluations per outer point, and each outer evaluation includes an inner nonlinear return-map solve. A few trials may be infeasible; a constant penalty is used. Starts are tiny randomized perturbations accepted only if feasible and initially better; `perturbed=False` means that seed fell back to the same initial point. No automatic restart or periodic checkpoint is provided for this local refinement, so use modest budgets first. The manifest captures input/code hashes and package versions.

The runner exports each candidate and evaluates the 12 original cycle checks, both onset initial conditions at .0203/.021, threshold crossings, adaptive first-return/fold residuals, and nearby branch root attempts. `pair_detected` means checked sample roots at the same gamma include one stable and one unstable orbit with sampled physical states; it is not a proof. `solver_success` only reflects the outer optimizer stop flag. Errors are conditional on cycles actually detected; `None` or unresolved is not a match. Onset and fold targets participate in fitting, so independent integration does not turn them into held-out data. Inspect JSON/logs, verify event routes and genuinely periodic cycles, then continue branches and check nondegeneracy before interpreting a fold.

To return results, stage only intended files: `git add -f runs/fm-first-return-01 fm-first-return-summary.txt`; inspect `git status --short`, commit and push.
