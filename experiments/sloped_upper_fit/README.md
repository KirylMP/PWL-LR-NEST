# Exploratory sloped upper threshold fit

This experiment fits a globally continuous piecewise-affine model in physical state coordinates (C, h), for each fixed IP3 input I. It uses the LR parameter cases and frozen physical comparison models from KirylMP/PWL-LR-NEST, main commit 416f56d8959990a1eeaef1a35ae6526f9b1ebeef; frozen data included in data/. AM K_ER=0.1, AFM=0.075, FM=0.05 uM.

F=[1,C,h,I,(C-C0)+,(C-g(I))+] @ coefficient_rows, with g(I)=C0+height*clip((I-I1)/(I2-I1),0,1). All region fields and threshold geometry are continuous in C, h, I. The model has two regions left of I1 and three on the right; h-column of the Jacobian is shared, and the matrices are constrained.

Run `python fit.py` (Python 3, NumPy, SciPy, Matplotlib). The program simulates LR for seven training inputs, samples the last two reference periods, and fits weighted instantaneous vector fields. It adds equilibrium residuals at 31 inputs, including the held-out input range, so holdout means held-out trajectories, not a fully unseen input domain. Geometry is optimized with three starts and bound constraints by variable projection; this is a local heuristic, not a global optimum. The target and train/holdout split are the repository's frozen validation data. Integration uses initial conditions listed in those data.

The frozen baseline is reconstructed from its alpha, beta, a, b and physical thresholds. Each PWA model is then separately integrated from the same LR initial state for max(450 s, 14 reference periods). Only peaks with tail-period and amplitude convergence checks are reported as cycles. A finite integration failing a detection criterion does not prove absence of a cycle. Domain guard: C in [-0.02,2], h in [-1,3]; this is a numerical guard, not a physical-validity proof. Peak sampling is a finite-resolution approximate measurement.

The preliminary starting fits in seeds/*.json give geometry, coefficient rows, eigenvalues in the three regions (sampled to the right of I2) and train/holdout comparisons. A newly generated results/comparison.png depicts only detected cycles, so missing points matter. The AM optimizer reaches both an I1 and height bound; its selected candidate leaves the numerical domain for all checked initial conditions. FM/AFM detected cycles are promising but neither local HLB1 nor unstable cycles, folds, exact event propagation, NEST performance, global stability, or complete branch structure are verified. Do not claim these are paper-ready or replace frozen models.

A model's HLB1 cannot be established by eigenvalues of regions alone; solve for the equilibrium crossing and check the appropriate local conditions. FM's middle region is a saddle; AFM's middle region is an unstable node for these fits. These do not establish the desired focus-focus HLB1.
