# PWL-LR-NEST

Рабочий проект для воспроизведения и исследования кусочно-аффинных
моделей кальциевой динамики астроцитов.

## Текущая основа

В `models/paper_frozen_v1/` сохранены шесть проверенных кандидатов:
AM, AFM и FM в физических и смешанных координатах. Манифест в этой
папке содержит происхождение и SHA-256 файлов.

Исходники перенесены из репозитория PWL-NEST:
- основной набор — коммит 4d19bca1577b04aeba3a0b0f4a36202d64cf58d2;
- `physical_no_fold` — коммит 39795a5.

В `astrocyte_lab/paper_models/` лежит копия того же набора по пути,
который ожидает исторический скрипт проверки. Это временное дублирование.

## Что проверено

На сервере выполнена независимая проверка шести моделей при длительности
450 с: для каждой найдены 4 из 4 проверочных циклов. Это не является
полным пересчётом статьи: оставшиеся модели, ветви циклов и NEST
требуют отдельной проверки.

## Важно

Рабочие скрипты пока используют историческую структуру и связи между
каталогами. Рефакторинг и единые команды запуска ещё впереди.
Новые результаты сохраняются отдельно и не добавляются в Git автоматически.

## Статья и новые эксперименты

- [`paper/`](paper/README.md) описывает закреплённый набор кандидатов и правила отбора результатов для статьи.
- [`experiments/`](experiments/README.md) содержит правила и шаблон для новых исследований.
- `python scripts/verify_paper_snapshot.py` проверяет файлы кандидатов и их исторические копии по манифесту.

Исторические каталоги и пути не переносились; наличие эксперимента в репозитории само по себе не означает, что его результаты включены в статью.
